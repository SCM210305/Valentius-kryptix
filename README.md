# Video Game Sales: Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a video game sales dataset using Python, Pandas, and Matplotlib. The objective is to understand the dataset's structure, investigate missing values, analyze statistical summaries, and identify patterns in video game sales.

## Objectives

- Examine dataset dimensions, data types, and memory usage.
- Identify and visualize missing values.
- Calculate descriptive statistics for numerical columns.
- Analyze categorical variables such as gaming platforms and genres.
- Create visualizations to investigate sales distributions, platform performance, genre sales, yearly trends, and regional relationships.
- Summarize the most important findings from the analysis.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

Dataset: Video Game Sales

Source: [Kaggle Video Game Sales Datasets](https://www.kaggle.com/datasets?search=video+game+sales)

The dataset contains information about video games, including their platforms, release years, genres, publishers, and sales across different regions.

## Project Structure

- `video_game_sales_eda.ipynb`: Jupyter Notebook containing the complete analysis.
- `README.md`: Project description and documentation.

## Analysis Performed

1. Dataset structural overview
2. Missing-value analysis
3. Descriptive statistics and categorical value counts
4. Visualization of global sales distribution
5. Comparison of platform and genre sales
6. Analysis of yearly sales trends
7. Comparison of North American and European sales

## Key Findings

The main findings are documented at the end of the Jupyter Notebook and are based on the observed data and visualizations.
